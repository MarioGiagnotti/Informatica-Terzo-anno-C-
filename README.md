# File scritti in C++

Questo è un semplice repository basato su **C++**.


## Tecnologie:
- **C++**

## Come testare i contenuti:

1. Clona il repository:

git clone https://github.com/MarioGiagnotti/Informatica-Terzo-anno-C-.git

oppure fare il Download del file .zip


2. Test delle applicazioni

     - aprire il Developer Command Prompt for Visual Studio (non PowerShell!)
     - spostarsi nella directory dove sono contenuti i file
     - compilare con:
        **cl nome_file.cpp**
     - cliccare sui file .exe
